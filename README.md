# 씨앤 트래블 매거진

거래처·고객에게 매주 보내는 여행 웹매거진입니다.
내용은 구글시트에서 관리하고, 이 저장소는 화면만 담당합니다.

- 입력 시트: [씨앤 트래블 매거진 입력 시트](https://docs.google.com/spreadsheets/d/1cX8qUQQuWU_UVcfqlo02rFAIOf8pbigKT226uemzgZg/edit)
- 웹매거진 주소: https://dongbeom-pi.github.io/cn-travel-webzine/

## 매주 발행 순서

1. **사진 올리기**
   GitHub 저장소 → `images` 폴더 → `Add file` → `Upload files` 로 사진을 끌어다 놓고 `Commit changes`.
   파일 이름은 영문·숫자로 짓습니다. 예: `2026-11-w3-cover.jpg`, `2026-11-w3-osaka.jpg`
2. **시트 작성**
   - `호수` 탭: 새 줄 추가. 공개는 `N`으로 두고 작성합니다.
   - `상품`, `팁`, `소식` 탭: 같은 호수 번호로 줄 추가. 사진 칸에는 파일 이름만 적습니다.
3. **미리보기**
   `웹매거진 주소?preview=1` 로 열면 공개 `N`인 호도 볼 수 있습니다.
4. **공개**
   `호수` 탭의 공개를 `Y`로 바꾸면 웹매거진 첫 화면이 새 호로 바뀝니다. (반영까지 1분 정도)
5. **메일 발송**
   `mail/email-template.html` 의 `[대괄호]` 부분을 바꿔 발송합니다.
   - 메일 제목 앞에 `(광고)` 를 붙입니다.
   - 이번 호 주소는 `웹매거진 주소?no=호수번호` 입니다.

## 시트 작성 규칙

| 항목 | 규칙 |
|---|---|
| 탭 이름, 첫 줄 제목 | 바꾸지 않습니다. 페이지가 이 이름으로 내용을 찾습니다. |
| 가격 | 숫자만 입력 (예: `390000`). 비우면 "가격 문의"로 표시 |
| 순서 | 작은 숫자가 먼저 나옵니다. |
| 사진 | `images` 폴더 파일 이름, 또는 `https://` 로 시작하는 주소 |
| 링크 | `https://` 로 시작해야 버튼이 나옵니다. |
| 팁·소식 | 그 주에 없으면 줄을 안 넣으면 됩니다. 섹션이 자동으로 빠집니다. |
| 상세설명 | 셀 안에서 줄바꿈(Alt+Enter)하면 팝업에서도 줄이 바뀝니다. |

시트는 링크가 있으면 누구나 볼 수 있도록 공개되어 있습니다. 내부 정보는 넣지 않습니다.

## 권장 사진 크기

| 용도 | 크기 | 비율 |
|---|---|---|
| 커버 | 1600 × 1000 | 16:10 (모바일은 16:9로 잘림) |
| 상품 | 1200 × 750 | 16:10 |

용량은 한 장에 500KB 이하로 줄여서 올리면 빨리 열립니다.
무료 사진은 [Pexels](https://www.pexels.com/ko-kr/) 에서 받을 수 있습니다.

## 주소 옵션

| 주소 | 화면 |
|---|---|
| `/` | 공개된 가장 최근 호 |
| `/?no=3` | 3호 |
| `/?preview=1` | 작성 중인 호 포함 미리보기 |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 구조 |
| `config.js` | 시트 ID, 매거진 이름, 문의처 (여기만 고치면 됨) |
| `assets/style.css` | 디자인 규격 (글자 6단계, 색 6개, 8px 간격) |
| `assets/app.js` | 시트를 읽어 화면을 그리는 코드 |
| `images/` | 사진 |
| `mail/email-template.html` | 발행 안내 메일 템플릿 |

## 처음 한 번만: GitHub Pages 켜기

저장소 → `Settings` → `Pages` → Source를 `Deploy from a branch`, Branch를 `main` / `(root)` 로 저장.
몇 분 뒤 웹매거진 주소로 접속됩니다.
