# 씨앤 트래블 매거진

거래처·고객에게 매주 보내는 여행 웹매거진이에요.

| 페이지 | 주소 | 누가 쓰나요 |
|---|---|---|
| 웹진 | https://dongbeom-pi.github.io/cn-travel-webzine/ | 고객 |
| 상품 올리기 | https://dongbeom-pi.github.io/cn-travel-webzine/submit.html | 각 부서·파트 |
| 관리자 | https://dongbeom-pi.github.io/cn-travel-webzine/admin.html | 편집 담당자 |

- 공개 입력 시트: [씨앤 트래블 매거진 입력 시트](https://docs.google.com/spreadsheets/d/1cX8qUQQuWU_UVcfqlo02rFAIOf8pbigKT226uemzgZg/edit)
- 접수 내역(담당자 연락처 포함)은 Apps Script가 만든 **비공개 시트**에 따로 쌓여요.

## 매주 흐름

1. **부서가 올려요**: 상품 올리기 페이지에서 5단계로 입력해요. (누가 → 무엇을 → 소개 → 사진 → 신청 받을 곳)
2. **관리자가 골라요**: 관리자 페이지 → 호수 관리 → `새 호 만들기` 로 이번 호를 만들어요. (처음엔 비공개)
3. **싣기**: `새로 들어온 상품` 에서 `웹진에 싣기` → 호수와 순서를 골라요. 안 실을 건 `반려`.
4. **팁·소식**: `팁 · 소식은 시트에서 고치기` 를 눌러 시트에 같은 호수 번호로 줄을 추가해요.
5. **확인**: 상단 `미리보기` 로 비공개 호까지 확인해요.
6. **공개**: 호수 관리에서 `공개하기`. 웹진 첫 화면이 새 호로 바뀌어요.
7. **메일 발송**: `mail/email-template.html` 의 `[대괄호]` 를 바꿔 보내요. 제목 앞에 `(광고)` 를 붙여주세요.

> https://dongbeom-pi.github.io/cn-travel-webzine/submit.html

> - 전단지·안내문은 "안내 이미지" 칸에 넣어주시면 상세 화면에 함께 나와요.

## 처음 한 번만: 서버(Apps Script) 설치

업로드·관리자 기능은 구글 Apps Script가 처리해요. 관리자 비밀번호는 이 저장소가 아니라 Apps Script 안에만 저장돼요.

1. 공개 입력 시트를 열고 `확장 프로그램` → `Apps Script`
2. 기본 코드를 지우고 따로 전달받은 `Code.gs` 내용을 붙여넣고 저장
3. 위쪽 함수 목록에서 `setup` 선택 → `실행` → 구글 계정 권한 허용
4. `배포` → `새 배포` → 톱니바퀴에서 `웹 앱` 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. `배포` 를 누르고 나온 **웹 앱 URL**(…/exec)을 `config.js` 의 `apiUrl` 에 넣기
6. 끝나면 `Code.gs` 맨 위의 `INITIAL_PW` 값은 지워도 돼요.

비밀번호를 바꾸려면 `Code.gs` 의 `changePassword` 함수 안에 새 비밀번호를 쓰고 실행한 뒤 다시 지워주세요.
코드를 고친 뒤에는 `배포` → `배포 관리` → 연필 → 버전 `새 버전` 으로 다시 배포해야 반영돼요.

## 시트 칸 규칙

| 항목 | 규칙 |
|---|---|
| 탭 이름, 첫 줄 제목 | 바꾸지 않아요. 페이지가 이 이름으로 내용을 찾아요. |
| 가격 | 숫자만. 비우면 "가격은 문의해 주세요" |
| 마감일 | 2026-11-23 형식. 7일 이내면 D-day, 지나면 "마감됐어요" |
| 사진·첨부이미지 | https:// 주소 또는 `images` 폴더 파일 이름. 첨부는 쉼표로 여러 개 |
| 링크 | 이메일이나 https:// 링크 |

## 주소 옵션

| 주소 | 화면 |
|---|---|
| `/` | 공개된 가장 최근 호 |
| `/?no=3` | 3호 |
| `/?preview=1` | 비공개 호 포함 미리보기 |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html`, `assets/app.js` | 웹진 |
| `submit.html`, `assets/submit.js` | 상품 올리기 (5단계) |
| `admin.html`, `assets/admin.js` | 관리자 |
| `assets/common.js` | 시트 읽기, 서버 호출, 사진 줄이기 |
| `assets/style.css` | 토스 스타일 디자인 규격 |
| `config.js` | 시트 ID, 서버 주소, 문의처 |
| `mail/email-template.html` | 발행 안내 메일 |
