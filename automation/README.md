# 자동화 지시 파일

`queue.json` 에 지시를 넣고 `main` 에 올리면, Apps Script가 **10분마다** 가져가서 실행해요.
관리자 페이지 맨 아래 **자동화 지시 지금 실행** 을 누르면 바로 실행돼요.

- 한 번 실행한 지시(`id`)는 다시 실행하지 않아요. 새 지시는 항상 새 `id` 를 써요. (예: `2026-11-17-01`)
- 실행 결과는 비공개 접수함 시트의 **자동화기록** 탭에 남아요. (실행일시 · 지시ID · 작업 · 결과 · 내용)
- 실행된 지시는 파일에서 지워도 돼요.
- 이 파일은 공개 저장소에 있어요. 담당자 연락처 같은 내부 정보는 넣지 않아요.

## 형식

지시마다 `id`(지시 번호), `action`(작업), `args`(작업에 넘길 값)를 써요.

```json
{
  "commands": [
    { "id": "2026-11-17-01", "action": "saveIssue",
      "args": { "isNew": true, "issue": { "호수": 3, "발행일": "2026-11-24", "주차표기": "11월 4주차",
                "커버제목": "…", "커버소개": "…", "커버사진": "https://…", "커버링크": "" } } },

    { "id": "2026-11-17-02", "action": "saveRow",
      "args": { "table": "상품", "row": { "호수": 3, "카테고리": "해외 여행", "상품명": "…", "한줄설명": "…",
                "가격": 429000, "마감일": "2026-11-30", "상세설명": "…",
                "사진": "https://…", "첨부이미지": "https://…, https://…", "링크": "PJ@CNCORP.KR" } } },

    { "id": "2026-11-17-03", "action": "saveRow", "args": { "table": "팁",  "row": { "호수": 3, "제목": "…", "내용": "…" } } },
    { "id": "2026-11-17-04", "action": "saveRow", "args": { "table": "소식", "row": { "호수": 3, "내용": "…", "링크": "https://…" } } },
    { "id": "2026-11-17-05", "action": "approve", "args": { "id": "CN261117-AB12", "issue": 3 } },
    { "id": "2026-11-17-06", "action": "setPublish", "args": { "no": 3, "value": "Y" } }
  ]
}
```

## 작업 목록 (`args` 에 넣을 값)

| action | args | 하는 일 |
|---|---|---|
| `saveIssue` | `issue` (호수 필수), `isNew` | 호 만들기 · 커버 고치기. 새 호는 비공개로 시작 |
| `setPublish` | `no`, `value` (`Y`/`N`) | 공개 · 비공개 |
| `deleteIssue` | `no` | 호와 그 호의 상품·팁·소식 삭제 |
| `saveRow` | `table` (`상품`/`팁`/`소식`), `row` | `row.id` 가 있으면 고치기, 없으면 추가 (순서는 맨 뒤) |
| `deleteRow` | `table`, `id` | 항목 삭제 |
| `reorder` | `table`, `ids` (원하는 순서대로) | 순서 바꾸기 |
| `approve` | `id` (접수번호), `issue` | 접수 상품을 그 호에 싣기 |
| `reject` | `id` (접수번호), `memo` | 접수 상품 반려 |

사진은 `https://` 주소를 그대로 넣어요. (예: Pexels 사진 주소)
현재 내용(상품 id 등)은 공개 시트, 접수 내역과 실행 기록은 비공개 접수함 시트에서 확인해요.
